# Project Context

Multi-tenant state as of 2026-08-12, branch `multiuser-web`. Design: [[MULTIUSER_PLAN]] · [[DECISIONS#D001]]
Scheduler feature set on top of it: branch `maintainer-scheduler`, [[SCHEDULER_PLAN]] · [[DECISIONS#D007]]
(section "Scheduler" at the bottom).

## Identity model

One **network key** = one in-game OC instance = one tenant. No user accounts:
the connector authenticates with the key, and humans log into the website with
the *same* key. Everyone holding a key is interchangeable; isolation is between
keys, not between people. Key is generated by `install-connector` on the OC
computer (32 chars a-z0-9) and lives in its `config.lua`.

## server/registries.js

- `REGISTRIES` — item registry catalog, keyed by id. Only `gtnh-2.9` today; new
  modpack version = drop `client/public/registries/<id>.json` + one entry here.
- `getRegistry(id)` — lazy-loads + caches `{id, label, file, atlas, icons: Map(label → {x,y})}`.
  Falls back to `DEFAULT_REGISTRY` for unknown ids. Searches `server/public/registries`
  (built) then `client/public/registries` (dev).

## server/db.js

- `DATA_DIR` = `process.env.DATA_DIR` → `RAILWAY_VOLUME_MOUNT_PATH` → `.` (exported; mkdir'd on boot).
- WAL mode + busy_timeout 5000.
- New tables: `networks (id, name, key_hash UNIQUE, registry, created_at, last_sync_at)`,
  `sessions (token, network_id, expires_at)` + index on expires_at. Session TTL 30d.
- `hashKey(key)` — sha256 hex. Keys are high-entropy machine secrets, so no scrypt;
  keeps `/api/sync` to one indexed lookup.
- `findNetworkByKey / getNetwork / createNetwork({name,key,registry,id?}) / touchNetwork(id,name) / setNetworkKey`
- `seedLegacyNetwork()` — mirrors env `API_KEY` onto network row `main` every boot
  (creates or re-hashes). Keeps pre-multiuser DBs + .env installs working.
- `createSession / getSessionNetwork / destroySession / sweepSessions`
- Removed: `getNetworks()` (was the tenant-enumeration leak).

## server/index.js

- `browserAuth` — session cookie → `req.networkId`. Never reads network from URL/body.
- `connectorAuth` — `Bearer <key>` → network row → `req.networkId`. Unknown key +
  `OPEN_REGISTRATION` (default true) + length ≥ 16 → auto-registers a new network;
  `OPEN_REGISTRATION=false` → 401. In `SINGLE_USER` mode any key claims `main`.
- `SINGLE_USER=true` — loopback browsers skip login and bind to `main`; used by start.bat.
- Routes: `:networkId` **removed everywhere** — `/api/targets[/:label]`, `/api/stock`,
  `/api/settings`, `/api/me`, `/api/login {key}`, `/api/logout`. `/api/networks` deleted.
- Legacy: `/api/login` also accepts env `BROWSER_PASSWORD` → network `main`.
- `/api/sync` — network from key only; optional `name` field updates display name;
  responds with that network's enabled targets + sleep.
- WS: `path: '/ws'`, cookie-authenticated on upgrade (close 4001 otherwise),
  `ws.networkId` stamped, `broadcast(networkId, data)` scoped per tenant.
- Rate limits: per-network sync (2s), per-IP login (10 / 5 min). Hourly sweep of
  sessions + stale rate-limit entries.
- Cookie: httpOnly, sameSite=lax, secure behind https, 30d.

## client/src/main.js

- Login screen asks for the **network key** (`/api/login {key}`).
- `init()`: `/api/me` → `{id, name, last_sync_at, registry:{id,label,url}}` →
  fetch registry from `registry.url` (`/registries/gtnh-2.9.json`) → data fetches.
- Network bar = name + registry + last-sync + Log out (no selector — one key one network).
- WS close 4001 → back to login instead of reconnect loop.
- localStorage keys still namespaced by network id, so per-network sort/groups survive.

## oc-scripts

- `install-connector.lua` — prompts server URL + name, generates 32-char key,
  writes config.lua, prints the key (re-run re-prints it). Reboot on Enter.
- `connector.lua` — refuses to run with key < 16 chars; sync body sends `name`,
  never a network id; logs `result.error` from server.
- `config.lua` — `api_key` (blank; installer fills), `name`; `network_id` removed.

## Deployment

- `Dockerfile` — 3-stage (client build / server deps / slim runtime), `DATA_DIR=/data`, VOLUME /data.
- `docker-compose.yml` — named volume `oc-maintainer-data` → `/data`; backup one-liner in comments.
- `railway.json` — numReplicas pinned 1 (SQLite). Volume documented in README (mount `/data`;
  `RAILWAY_VOLUME_MOUNT_PATH` picked up automatically by db.js).
- `start.bat` — writes `PORT`, `DATA_DIR=data`, `SINGLE_USER=true`; no password prompts.
- Registry moved: `client/public/gtnh_registry.json` → `client/public/registries/gtnh-2.9.json`;
  `server/data/gtnh_registry.json` duplicate deleted.

## Env vars

`PORT`, `DATA_DIR`, `OPEN_REGISTRATION` (default true), `SINGLE_USER`,
legacy: `API_KEY`, `BROWSER_PASSWORD`.

# Scheduler

## Schema additions

- `targets` + `group_id INTEGER` (NULL = ungrouped), `position INTEGER DEFAULT 0`
  (0 everywhere until first drag; `ORDER BY position, rowid` keeps old rows put).
- `settings` + `cpu_limit INTEGER DEFAULT 0`, `default_run_seq INTEGER DEFAULT 0`.
- `groups (network_id, id, name, collapsed, interval_s NULL, min_tps NULL, run_seq)`,
  PK `(network_id, id)`, ids chosen by the browser.
- All added in CREATE TABLE *and* as try/catch ALTERs, matching the `enabled` pattern.

## server/db.js

- `getGroups / replaceGroups / updateGroup / deleteGroup / bumpRunSeq / setTargetOrder`.
- `replaceGroups` — replace-all for membership; omitted fields keep stored values,
  `run_seq` survives an id, then `pruneGroups` drops groups under two members and
  releases orphaned members. Also runs after `deleteTarget`.
- `setSettings(networkId, patch)` merges instead of overwriting.

## server/index.js

- `GET/PUT /api/groups`, `PUT|DELETE /api/groups/:id`, `PUT /api/order`,
  `POST /api/run-now[/:groupId]`, `GET /api/status`. All `browserAuth`.
- `/api/sync` response gains `groups[]`, `cpu_limit`, `default_run_seq`, `now`
  (Date.now(), the maintainer's only real clock) and `group_id` per target.
- `lastStatus` Map holds the maintainer's last status blob for `/api/status`;
  broadcast dedup split from the DB-write dedup (TPS changes every poll).
- `broadcastLayout` sends `targets` + `groups` together — membership lives on the
  targets, so half an update draws a torn layout.

## client/src/main.js

- `loadGroups()` rebuilds `{id, name, labels[], interval_s, min_tps}` from `groups`
  + `targets.group_id`; `saveGroups(next)` optimistically patches both local copies,
  redraws, PUTs, refetches. `patchGroup / removeGroup / runNow` for single edits.
- `ORDERED_MODES = ['default','custom']` — brackets draw in both, gestures need Custom.
- `renderSchedulePanel()` below the add panel: default-schedule row + one row per
  group (interval, min_tps, check age, Run now). Skips redraw while focused.
- `migrateLocalLayout()` uploads `maintainer_groups_*` / `maintainer_custom_order_*`
  once (order first, then groups) and deletes them; keeps them on failure.
- `updateLiveMeta()` paints TPS + busy/total CPUs into the network bar.

## oc-scripts/level-maintainer

- `src/scheduler.lua` — `ticks()` (= `uptime * 20`), `sample()`, `feedRealTime(s)`,
  `tps()`, `clockSource()`. See [[DECISIONS#D007]] for why not the world clock.
- `src/state.lua` — `/home/maintainer-state.lua`, serialized Lua, `load/save/path`.
- `src/chunk.lua` — `send(tunnel,payload)` (unframed while it fits, else
  `c|id|i|n|body` frames), `receiver()`, `feed(rx,msg)`. Mirrored verbatim at
  `web-connector/chunk.lua`; both installers fetch their own copy.
- `src/ae2.lua` — `crafting()` now also returns `{total, busy}` CPU counts from the
  same `getCpus()` walk.
- `maintainer.lua` — schedule keys (`0` = default, else group id), `nextRun` /
  `checkedAt` / `lastGroupSeq` bookkeeping, per-cycle CPU budget, sticky per-item
  status (`crafting/requested/failed/waiting_cpu`), status payload with `tps`,
  `cpus` and `group_checked` (string keys, or the connector's JSON encoder would
  turn them into an array). `event.pull` instead of `os.sleep` so a push wakes it.
- `config.lua` — `cpu_limit`, optional 4th slot per item (group id), `groups` table;
  only used until a push lands, then the state file wins.

## oc-scripts/web-connector

- `connector.lua` — one config blob (targets, groups, cpu_limit, default_run_seq,
  sleep) pushed on change through `chunk.send`; relays `now:<ms>` every poll;
  `ask()` reassembles multi-frame replies. `setsleep:` removed (folded into the blob,
  still honoured by the maintainer for older connectors).
